The Home Manager configuration installs the xremap systemd service, and the Hyprland
configuration starts it. You only need to follow the instructions
[here](https://github.com/kmonad/kmonad/blob/master/doc/faq.md#q-how-do-i-get-uinput-permissions)
and then reboot the system so that xremap has the necessary permissions to run in
user mode.
